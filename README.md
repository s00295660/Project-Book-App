This Book App is designed to make book search easy by displaying a catalogue of books sorted by genres and by authors. 
All users have their own library in which there are the books that they have read and they also have a wish-list that is for the books they want to read.
They can grade the books read using stars and add a comment.
The app have a user-friendly interface, books can be filtered by genres and authors.


User guide:
Click on the Profile button and enter your username in the white textbox, then press Enter.
You can go back to the Menu window clicking on the Back button.
The Search button is to search books, if you click on it a new window opens. You can search books using the author and/or the genre. The titles of the books appear in the list, if you click on a title the cover
and the description appear. You can add a book to your wish-list using the Add button.
You can go back to the Menu Window clicking on the Back button.
If you go on your profile the book is in your wish-list. If you have read it, you can click on the Read button, the book disappear from the wish-list, the number of books read increases by one and the book is added 
to your library.
If you go back to the Menu window and then click on the Library button, you can see that the book is in the list of your library.
You can grade a book by clicking on it and selected a number of stars, you can also add a comment in the textbox.
